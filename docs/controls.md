# Controls & Interface

## Click wheel controls

Start a gesture on the outer ring and move around it to scroll lists or adjust volume on **Now Playing**. You can also tap list items directly.

| Button | Browsing | Now Playing |
| --- | --- | --- |
| **Center** | Select highlighted item | Return to library |
| **Menu** | Return to main menu | Return to main menu |
| **Previous** | Go back | Previous track |
| **Next** | Select highlighted item | Next track |
| **Play/Pause** | Open Now Playing | Play / Pause |

### Long-press shortcuts

- **Hold Menu:** Open quick settings.
- **Hold Center (browsing):** Open the context menu for the highlighted item.
- **Hold Center (Now Playing):** Open track actions, including **Output info** for playback and USB diagnostics.

## Interface customization

Cymatic follows your device's system light and dark theme automatically. Open **Settings → Interface** to tailor the wheel and display:

- **Click wheel:** Adjust wheel sensitivity, gesture pause, wheel size, and haptic feedback.
- **Display:** Configure screen padding, text scrolling (speed and start delay), default cover-art visibility, and keep-screen-awake mode.

## Standby mode

Enable the optional idle timeout under **Settings → Interface** to blank the player display when inactive. Touch anywhere on the screen to wake it, and continue smoothly into a wheel gesture without lifting your finger.

## Per-device audio profiles

Cymatic remembers audio settings per output device:

- Separate volume memory for each device, including distinct normal and direct USB volume levels.
- Per-device equalizer presets.
