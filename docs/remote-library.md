# Remote Library & Offline Downloads

Cymatic can connect to a remote music library and blend its songs and playlists directly into your normal library. [AudioStream](https://github.com/PXR05/audiostream) is currently supported, with additional providers planned.

## Connecting an account

1. Open **Settings → Remote library** (or choose **AudioStream** during first-launch onboarding).
2. Enter your AudioStream server URL, username, and password.

Once connected, your remote songs and playlists appear alongside any local music right away. Tap any remote track to stream it. If a downloaded copy exists, Cymatic plays the offline copy automatically.

*Note: Local storage permission is not required if you only listen from a remote library.*

## Saving music offline

Long press any song, album, artist, or playlist and choose **Keep offline** to download it. You can keep queueing more items while downloads are running, and status icons update as files finish:

| Icon | Meaning |
| --- | --- |
| Animated icon | Queued or downloading |
| Download icon | Available offline |
| Half-filled circle | Partially available offline |
| Cloud icon | Stream-only |

## Storage & automatic downloads

Cymatic manages offline storage automatically. Additional options are available under **Settings → Remote library**:

- Custom download folders and layout
- Bulk downloads
- Scheduled automatic downloads (defaults to a daily Wi-Fi check when first enabled)

Uninstalling Cymatic removes its private offline downloads.

## Filtering by offline status

Hold **Menu → Show** on any library screen to filter what is displayed:

- **All music**
- **Offline only**
- **Not offline** (includes partially offline playlists)

The active filter is shared across library screens and remembered across sessions. Tap the active filter label or open **Menu → Show** again to return to all music.
